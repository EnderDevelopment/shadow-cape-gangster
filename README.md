# Minecraft Character Texture

Shadow Cape Gangster is a 64×64 SVG character illustration for a Minecraft texture project. It depicts a gangster wearing a black jacket, black pants, and a dark cape, with a red tie and a brimmed hat.

## Install

1. Download or clone the project.
2. Open `assets/textures/gangster_caped_skin.svg` in an SVG-compatible viewer or editor.

## Use

1. View the SVG as a character illustration or use it as a visual reference.
2. To use the design in Minecraft, adapt it to the skin or texture format required by your game and tools. The included SVG is not itself a Minecraft-ready skin file.
